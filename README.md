# PWCFinancialAnalysis

Data, models, and extraction pipelines for a five-year revenue and expenditure analysis of Prince William County, Virginia (FY27–FY31).

## Scope

This repository contains the **descriptive, reproducible** layer of a broader fiscal-risk analysis:
- Source documents (PWC budgets, ACFRs, CIP, state and federal data) as originally published.
- Curated extractions (CSV, BibTeX) tied to page-numbered citations.
- Python models that produce a three-scenario five-year revenue/expenditure projection.
- Chart-generation code producing every figure from the committed inputs.

It is intentionally **neutral**: it does not advocate for any policy outcome or take a position on the Prince William County Board of Supervisors' 2024–2026 Digital Gateway decisions. Users can run the model, inspect the data, and form their own conclusions.

A separate, private repository consumes this one via a Git submodule and produces a policy-facing report on top of these outputs.

## Repository layout

```
data/
  *.csv                       curated inputs and scenario outputs
  raw/
    pdfs/                     source PDFs (PWC budgets, ACFRs, CIP, state reports)
    text/                     text extractions of each PDF
    stage3b/                  peer-county Census BPS permit files, Moody's methodology,
                              Virginia APA comparative-report spreadsheets
model/
  revenue_drivers.py          non-DC revenue projection (residential RE, commercial,
                              personal property, BPOL, sales tax, meals, state aid)
  expenditures.py             committed-expenditure path (schools, public safety,
                              debt service on the approved CIP, pension/OPEB)
  pwc_5yr.py                  integrated scenario model
  pwc_5yr.xlsx                shareable workbook (regenerated by pwc_5yr.py)
figures/
  make_figures.py             regenerates every PNG figure from scenario CSVs
  *.png                       rendered figures
citations/
  stage1.bib … sources.bib    per-stage bibliographies; sources.bib is the master
research/
  *.md                        methodology notes and data-extraction write-ups
```

## Reproducibility

From a clean checkout with Python 3.11+ and `pip install pandas openpyxl matplotlib`:

```bash
# Non-DC revenue drivers
python model/revenue_drivers.py

# Expenditure path
python model/expenditures.py

# Integrated 5-year scenario model (reads revenue_drivers + expenditures outputs)
python model/pwc_5yr.py

# Regenerate figures from scenario CSVs
python figures/make_figures.py
```

Every number in every figure traces to a file in `data/`, which in turn cites a page of a source document in `data/raw/`.

## Scenarios

The integrated model produces three scenarios over FY27–FY31:

| Scenario | Definition |
|---|---|
| **Pre-Cancellation Digital Gateway** | Counterfactual baseline assuming the Digital Gateway CPA and associated rezonings proceed on the schedule originally approved by the Board. |
| **CAPEX Spillover** | Cancelled Pageland projects plus a peer-county-calibrated reduction in new overlay CAPEX plus accelerated asset write-downs as operators re-price regulatory risk. |
| **Partial Recovery** | County reverses course within 1–2 years via settlement, new zoning action, or clarifying resolution; CAPEX partly returns with a confidence discount. |

Each scenario reports revenue by source, total expenditure, surplus/deficit, the real-estate tax rate required to close the gap, debt-capacity impact, and reserve trajectory.

## Data sources

Primary:
- Prince William County Office of Management and Budget: adopted budgets (FY25, FY26, FY27), proposed budgets, Capital Improvement Program, five-year financial forecasts.
- Prince William County Department of Finance: Annual Comprehensive Financial Report (FY24, FY25), Popular Annual Financial Report.
- Prince William County Planning Office: Digital Gateway CPA records, overlay maps, rezoning files.
- Virginia Joint Legislative Audit and Review Commission: data-center economic impact reports.
- Virginia Auditor of Public Accounts: comparative local-government reports.

Supplementary:
- U.S. Census Bureau Building Permits Survey (county-month panels).
- U.S. Bureau of Labor Statistics QCEW and BEA federal workforce series.
- Moody's Investors Service U.S. Cities and Counties rating methodology (July 2024).
- Peer-reviewed and industry studies on data-center fiscal multipliers (Mangum Economics, George Mason University Stephen S. Fuller Institute, Chmura Economics).

Every figure and model output has a page-level citation in `citations/`.

## Not in this repository

This repository is the reproducible analytic layer. It **does not** contain:
- The policy-facing supervisor report.
- Narrative interpretation of whether the Board's decisions were prudent.
- Author opinion.

Those are in a separate private repository maintained by the author.
